APLICACIÓN PARA UNA COMPAÑÍA DE HOSPEDAJE DE PAGINAS WEB 

ChibchaWeb es una empresa de hospedaje de páginas Web, 
ofrece tres tipos de paquetes de “hosting” sobre plataformas Windows y Unix: 
Chincha-Platino, Chibcha-Plata y Chibcha-Oro. 
Cada cliente puede escoger uno de cuatro posibles planes de pago: 
Mensual, trimestral, semestral o anual usando tarjetas de crédito

Metodología seleccionada para la gestión y desarrollo del proyecto centrada en el marco ágil Scrum con Jira.
Uso de arquitectura de tres capas
Angular, MySQL, Flask
Despliege Netlify y AwsCloud
